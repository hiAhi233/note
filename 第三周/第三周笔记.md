# 线性回归

## 矩阵形式

当有 p个特征时，模型形式：

y=β0+β1x1+β2x2+⋯+βpxp+ε

设计矩阵 X，参数向量 β=[β0,β1,…,βp]T，因变量向量 Y=[y1,y2,…,yn]T，矩阵形式为：

Y = Xβ + ε



## 最小二乘法

线性回归的核心优化准则是**最小化残差平方和（SSE）**，即最小二乘法

1.损失函数定义

残差 ei=yi−yi_pred，残差平方和：

J(β)=∑~i=1~^n^ei^2^=∑~i=1~^n^(yi−yi_pred) ^2^=(Y−Xβ)^T^(Y−Xβ)



对损失函数 J(β) 关于 β 求导，并令导数为 0,得到正规方程组：

X^T^Xβ=X^T^Y

若 X^T^X可逆（满秩），则参数的解析解为：

β_=(X^T^X)^−1^X^T^Y



## 模型特点

- **任务类型**：回归任务，预测连续型数值
- **输出范围**：任意实数 (−∞,+∞)
- **参数求解**：有解析解（正规方程），无需迭代
- **损失函数**：均方误差（MSE）J(β)=n1∑i=1n(yi−y^i)2
- **假设条件**：线性、独立性、同方差、正态性（高斯 - 马尔可夫定理）
- **可解释性**：参数 βi 直接表示特征 xi 对 y 的边际影响



# 逻辑回归

逻辑回归是**广义线性模型**，本质是二分类模型，通过 Sigmoid 函数将线性回归的连续输出映射为 0~1 的概率，用于分类任务。

#### 1.Sigmoid 激活函数

σ(z)=1/(1+e^−z^)

	- 性质：单调递增，值域 (0,1)，导数 σ′(z)=σ(z)(1−σ(z))


#### 2.极大似然估计（参数求解）

逻辑回归无解析解，需通过**极大似然估计**结合梯度下降迭代求解参数。

#### (1) 似然函数定义
对于二分类问题，单个样本的概率分布：
$$
P(y_i|X_i) = \hat{y}_i^{y_i} (1 - \hat{y}_i)^{1-y_i}
$$
所有样本的似然函数：
$$
L(\beta) = \prod_{i=1}^n P(y_i|X_i) = \prod_{i=1}^n \hat{y}_i^{y_i} (1 - \hat{y}_i)^{1-y_i}
$$
取对数似然（简化计算）：
$$
\ell(\beta) = \log L(\beta) = \sum_{i=1}^n \left[ y_i \log \hat{y}_i + (1 - y_i) \log(1 - \hat{y}_i) \right]
$$


#### （2）损失函数（交叉熵）



逻辑回归的损失函数为**交叉熵损失**，是负对数似然：
$$
J(\beta) = -\frac{1}{n}\ell(\beta) = -\frac{1}{n} \sum_{i=1}^n \left[ y_i \log \hat{y}_i + (1 - y_i) \log(1 - \hat{y}_i) \right]
$$
矩阵形式：
$$
J(\beta) = -\frac{1}{n} \left[ Y^T \log(\hat{Y}) + (1 - Y)^T \log(1 - \hat{Y}) \right]
$$

预测概率向量：
$$
\hat{Y} = \sigma(X\beta)
$$



#### (3) 梯度推导与参数更新

对损失函数求导：
$$
\frac{\partial J(\beta)}{\partial \beta} = -\frac{1}{n}X^T(Y - \hat{Y})
$$


梯度下降参数更新：
$$
\beta_{t+1} = \beta_t - \eta \cdot \frac{\partial J(\beta)}{\partial \beta} = \beta_t + \frac{\eta}{n}X^T(Y - \hat{Y})
$$
其中η为学习率，控制参数更新步长

#### 3. 模型特点

- **任务类型**：分类任务（二分类，可拓展为多分类）
- **输出范围**：0~1 之间的概率值
- **参数求解**：无解析解，需梯度下降等迭代优化
- **损失函数**：交叉熵损失（负对数似然）
- **假设条件**：无严格正态 / 同方差假设，仅需线性可分（近似）
- **可解释性**：参数 βi 对应对数几率 log(P(y=0)P(y=1)) 的变化



# 异同点

## 相同点

| 维度         | 共性说明                                         |
| ------------ | ------------------------------------------------ |
| **模型基础** | 均以**线性组合** Xβ 为核心，本质是线性模型的拓展 |
| **参数含义** | βi 均表示特征对目标变量的影响权重                |
| **优化目标** | 均通过最小化损失函数求解最优参数                 |
| **特征处理** | 均需特征标准化 / 归一化，提升模型收敛性与稳定性  |
| **可解释性** | 均为白盒模型，参数可解释性强                     |

## 不同点

| 对比维度     | 线性回归                       | 逻辑回归                                      |
| ------------ | ------------------------------ | --------------------------------------------- |
| **任务类型** | 回归任务，预测连续值           | 分类任务，预测类别 / 概率                     |
| **输出形式** | 任意实数 (−∞,+∞)               | 0~1 之间的概率值（经 Sigmoid 映射）           |
| **损失函数** | 均方误差（MSE）                | 交叉熵损失（负对数似然）                      |
| **参数求解** | 有解析解（正规方程），一步求解 | 无解析解，需梯度下降迭代                      |
| **假设条件** | 需满足线性、同方差、正态性等   | 无严格分布假设，仅需近似线性可分              |
| **评估指标** | MSE、RMSE、R2 等回归指标       | 准确率、精确率、召回率、F1、AUC 等分类指标    |
| **适用场景** | 连续值预测（如房价、销量）     | 二分类 / 多分类任务（如疾病诊断、好坏酒分类） |
| **输出解释** | 直接预测目标变量的数值         | 预测样本属于正类的概率，需阈值（如 0.5）分类  |



# K-Means聚类模型

## 核心原理
K-Means是经典的**无监督聚类算法**，核心思想是：将$n$个样本划分为$K$个互不重叠的簇，使得**簇内样本相似度最高，簇间样本差异最大**，最终通过最小化簇内平方和（SSE）实现最优划分。

## 公式推导

### 1. 目标函数（簇内平方和 SSE）
K-Means的优化目标是最小化所有样本到其所属簇中心的欧氏距离平方和：
$$
SSE = \sum_{i=1}^{K} \sum_{x \in C_i} \| x - \mu_i \|_2^2
$$

- K：预设的聚类簇数量
- C_i：第$i$个簇的样本集合
- μ~i~：第i个簇的簇中心（质心）
- | x - μ~i~ \|_2^2：样本x到簇中心μ~i~ 的欧氏距离平方

### 2.更新簇中心（固定样本分配，更新中心）
固定样本分配后，对SSE关于$\mu_i$求偏导并令导数为0，求解最优簇中心：
$$
\frac{\partial SSE}{\partial \mu_i} = -2 \sum_{j=1}^{n} r_{ji} \cdot (x_j - \mu_i) = 0
$$
簇中心计算公式:
$$
\mu_i = \frac{\sum_{j=1}^{n} r_{ji} \cdot x_j}{\sum_{j=1}^{n} r_{ji}} = \frac{1}{|C_i|} \sum_{x \in C_i} x
$$

## 优缺点

### 优点

1. **原理简单、实现容易**：核心逻辑清晰，代码实现复杂度低，计算效率高
2. **时间复杂度低**：时间复杂度为O(nKt)（t为迭代次数），适合大规模数据集
3. **可解释性强**：簇中心直观可解释，聚类结果易理解
4. **通用性强**：适用于球形、凸形分布的数据集，应用场景广泛

###  缺点

1. **需预设簇数K**：K的选择直接影响聚类效果，实际应用中难以确定最优K
2. **对初始簇中心敏感**：随机初始化易陷入局部最优，不同初始值可能得到不同结果
3. **对异常值 / 噪声敏感**：异常值会显著影响簇中心的计算，导致聚类结果偏差
4. **仅适用于凸形数据集**：无法处理非凸、不规则形状的簇（如环形、嵌套簇）
5. **假设簇大小 / 密度均匀**：对大小、密度差异大的簇聚类效果差
6. **只能处理数值型数据**：无法直接处理类别型特征，需额外编码转换
